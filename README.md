# AI Course Notebooks

大学講義で使用した Google Colab ノートブックを纏めたリポジトリです．<br>
This repository contains Google Colab notebooks used in a university course. 

講義内容は，**機械学習，深層学習，LLM（大規模言語モデル）** を含みます．<br>
Topics include **Machine Learning, Deep Learning, and Large Language Models (LLMs)**.

日本語版と英語版のノートブックがあります． <br>
Both Japanese and English versions are provided.
