Supervised Classification of MNIST (Handwritten Digits)¶

The goal of this hands-on exercise is to help you understand the overall workflow of building a deep learning model.

Goal: Classify handwritten digits from "0" to "9"¶

The MNIST database (Modified National Institute of Standards and Technology database) is an image dataset of handwritten digits from "0" to "9". It is often used as a practice dataset in machine learning and deep learning. Many Python libraries also provide it as a ready-to-use sample dataset.

Sample images from the MNIST test dataset:

MNIST database (Apr. 12, 2023, 00:15 UTC). In Wikipedia: The Free Encyclopedia. Retrieved from https://en.wikipedia.org/wiki/MNIST_database

In this notebook, we will use a deep learning model to automatically classify handwritten digit images from "0" to "9".

Available information (input data type): handwritten digit images from "0" to "9"
Target result (output data type): classification into numeric labels from "0" to "9"

One useful feature of this dataset is that several standard preprocessing steps have already been applied, so we can use it easily as real data:

  • The size of the handwritten digits is standardized.
  • Each handwritten digit is placed at the center of the image.
  • The dataset is already split into training data and test data.
    • Training: 60,000 samples, Test: 10,000 samples
  • Ground-truth labels are already assigned.

Original paper: Y. LeCun, L. Bottou, Y. Bengio and P. Haffner, "Gradient-based learning applied to document recognition," in Proceedings of the IEEE, vol. 86, no. 11, pp. 2278-2324, Nov. 1998, doi: 10.1109/5.726791.

Fix the random seed for pseudo-random number generators¶

  • This fixes the pseudo-random number sequences generated and used in the code below.
  • A random seed is the value used to initialize a pseudo-random number generator.
  • If you do not set it explicitly, it is usually initialized from the current time or a similar value.
  • In this notebook, we fix the random seed to improve reproducibility, so anyone running the notebook can get the same pseudo-random sequence.

Note: In Colab, perfect reproducibility may still be difficult because the assigned CPU/GPU and library versions can differ.

In [ ]:
def set_seed(seed=123):
    # Fix the hash seed.
    os.environ["PYTHONHASHSEED"] = str(seed)
    # Make TensorFlow operations deterministic.
    os.environ['TF_DETERMINISTIC_OPS'] = 'true'
    # Make cuDNN operations deterministic.
    os.environ['TF_CUDNN_DETERMINISTIC'] = 'true'
    # Fix the seed for Python's standard random library.
    random.seed(seed)
    # Fix the seed for NumPy.
    np.random.seed(seed)
    # Fix the seed for TensorFlow.
    tf.random.set_seed(seed)

About the role of each dataset:

Purpose Description
Training dataset Data used to train the model
Validation dataset
Evaluation dataset		 Data used during training to check model accuracy.
It is recorded at each training iteration to evaluate whether performance on unseen data is improving (that is, whether the model is generalizing).
Test dataset Data used to test the accuracy of the final model.

What is the difference between a validation dataset and a test dataset in machine learning / deep learning?

  • The validation dataset is used as a reference when humans adjust hyperparameters.
  • The test dataset is used only to evaluate the final model after hyperparameter tuning and training are finished.

By preparing a test dataset that is never used for model training or parameter tuning, we can simulate how the model will perform on unseen data. If we use a dataset that was already used for training or hyperparameter tuning to evaluate the final model, the result will usually look better than real-world performance.

Normalize the dataset (Min-Max Normalization)¶

The images in this dataset are grayscale images made of integer values from 0 to 255.

Normalization (Min-Max Normalization) is a method that scales values to the range from 0 to 1 when the minimum and maximum are known. In image processing, it is often used to reduce training cost.

$$ X_{norm} = rac{X−X_{min}}{X_{max}−X_{min}} $$

Note: Min-Max Normalization is strongly affected by outliers. If the maximum and minimum are not fixed, or if outliers are present, other methods are often used.

Define the model¶

In [ ]:
# Define the model

# Input layer
inputs_images = tf.keras.layers.Input(shape=(28, 28, 1), name='input')

# Flatten layer
# (None, 28, 28, 1) -> (None, 784)
x = tf.keras.layers.Flatten()(inputs_images)

# Dense layers
# (None, 784) -> (None, 512)
x = tf.keras.layers.Dense(units=512, activation='relu', name='fc_1')(x)
# (None, 512) -> (None, 256)
x = tf.keras.layers.Dense(units=256, activation='relu', name='fc_2')(x)
# (None, 256) -> (None, 128)
x = tf.keras.layers.Dense(units=128, activation='relu', name='fc_3')(x)
# (None, 128) -> (None, 10)
outputs = tf.keras.layers.Dense(units=10, activation='softmax')(x)

model = tf.keras.Model(inputs=inputs_images, outputs=outputs, name='mnist_model')

# Compile the model (set the optimization algorithm, loss function, evaluation metric, etc.).
# You will learn about the loss function in Section 2.6.
model.compile(optimizer='adam',
              loss='categorical_crossentropy',
              metrics=['accuracy'])

# Print the model structure as text.
model.summary()

Draw a confusion matrix¶

Let us check the results using a confusion matrix. A confusion matrix looks like the table below.

↓ True label / Predicted label → 0 1 2 3 ...
0 Correctly predicted as 0 Predicted as 1 even though it is 0 Predicted as 2 even though it is 0 Predicted as 3 even though it is 0 ...
1 Predicted as 0 even though it is 1 Correctly predicted as 1 Predicted as 2 even though it is 1 Predicted as 3 even though it is 1 ...
2 Predicted as 0 even though it is 2 Predicted as 1 even though it is 2 Correctly predicted as 2 Predicted as 3 even though it is 2 ...
3 Predicted as 0 even though it is 3 Predicted as 1 even though it is 3 Predicted as 2 even though it is 3 Correctly predicted as 3 ...
... ... ... ... ... ...

The diagonal cells represent correct answers, such as "Correctly predicted as 0", "Correctly predicted as 1", and so on.
